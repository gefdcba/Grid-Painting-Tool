# 网格填色工具

一个纯前端的网格填色小工具，单个 HTML 文件即可运行，无需安装任何依赖。

## 用法

打开网页后：

1. **生成网格**：输入 `n`（1 ~ 60），点击「生成网格」，得到 n × n 的空白网格。
2. **选择颜色**：点击调色板色块，或直接按键盘 `1`~`9`、`0` 切换当前颜色。
3. **手动填色**：
   - 单击空白格 → 填上当前颜色；再点已填色的格子 → 恢复为空白。
   - 按住鼠标（或手指）拖拽可连续操作：起始格为空则一路染色，起始格已有颜色则一路取消染色。
4. **批量填色**：在「批量填色」框内粘贴文本，第一行写 `n`，之后 n 行每行 n 个颜色编号，按 `编号 % 10` 取色；负数或缺失的数字视为空格。点击「应用批量填色」即可。
5. **调整尺寸**：重新输入 n 并生成时，以左上角为基准保留重叠区域的颜色——n 变大新增格子为空，n 变小则裁掉超出范围的颜色。
6. **清空**：点击「清空颜色」一键清除所有已填颜色。

### 颜色编号

| 编号 | 颜色 | 编号 | 颜色 |
| :--: | :--: | :--: | :--: |
| `1` | 红 | `6` | 蓝 |
| `2` | 橙 | `7` | 紫 |
| `3` | 黄 | `8` | 粉 |
| `4` | 绿 | `9` | 棕 |
| `5` | 青 | `0` | 黑 |

### 批量填色示例

```
3
1 2 3
4 5 6
7 8 9
```
